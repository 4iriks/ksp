# Практическая работа 7

## Знакомство с React

Проект реализует React-компонент `ProfileCard`.

В компоненте есть:

- заголовок `Моя визитка`;
- имя студента;
- специальность;
- номер группы;
- краткое описание;
- список навыков;
- загрузка изображения для аватарки.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Адрес для открытия в браузере:

```text
http://127.0.0.1:5177/
```

## Проверка сборки

npm.cmd run build
