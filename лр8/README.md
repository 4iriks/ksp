# Практическая работа 8

## React, работа с API

Проект реализует React-страницу с визиткой студента и списком пользователей, полученным из тестового API.

В проекте есть отдельные компоненты:

- `ProfileCard` — показывает визитку студента и позволяет загрузить аватарку;
- `UsersList` — загружает пользователей из `/api/users.json`;
- `UserCard` — отображает одного пользователя в списке.

В каждом компоненте используется:

- `useState` для хранения данных, загрузки и ошибки;
- `useEffect` для запроса при открытии страницы;
- `fetch` для получения JSON;
- `map()` для вывода списка;
- уникальный `key` для каждого элемента списка;
- сообщение `Загрузка...`;
- сообщение `Ошибка загрузки данных`.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Адрес для открытия в браузере:

```text
http://127.0.0.1:5178/
```
